===============
School Deposit
===============

Lets a school use the deposits that parents pay on admission and
enrollment payment terms to settle later student invoices. A deposit
type tells the school which liability account holds the deposit, which
products identify a deposit and which products it may settle. A
deposit realization document then names the invoice being settled and
the deposit journal items used for it. This first version provides the
master data and the document with its workflow only; it has no
accounting effect yet.

Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-school-deposit
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *School Deposit*
6.  Install the module
